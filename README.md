# Football Market Value Prediction with Machine Learning

## Overview

This project was developed as part of my Master's Final Project (TFM) and focuses on applying Machine Learning techniques to football market valuation.

The main objective is to analyze football player data and develop predictive models to estimate market values, with the aim of identifying potentially undervalued players and exploring data-driven opportunities in the transfer market.

## Objectives

- Analyze football player data and market value patterns.
- Apply Machine Learning techniques to market value prediction.
- Evaluate model performance and compare predictive results.
- Explore how data analysis can support player scouting and transfer market decisions.

## Project Contents

- **`TFM_Futbol_ML.ipynb`** — Original Jupyter notebook containing the analysis and Machine Learning workflow.
- **`TFM_Futbol_ML.html`** — HTML export of the notebook for easier viewing.
- **`TFM_presentacion.pptx`** — Project presentation.
- **Master's Final Project report (PDF)** — Written documentation of the project.

## Technologies

Python · Jupyter Notebook · Google Colab · Machine Learning

The notebook can be opened using Jupyter Notebook or Google Colab. Additional dependencies and data requirements should be checked in the notebook before reproducing the analysis.
